# 資料分析與視覺化專案規範

## 1. 專案目標
- 使用 Python 進行資料檢查、分析與視覺化。
- 根據資料特性及使用者需求，選擇適當工具與圖表。
- 所有分析與結論必須以實際資料及執行結果為依據。
- 使用者明確指定的需求優先於本文件的預設做法。

## 2. 工作流程
1. 讀取資料並完成資料品質檢查。
2. 根據任務提出適合的分析問題。
3. 決定清理、轉換與彙整方式，記錄理由。
4. 選擇繪圖套件及圖表，簡述選擇原因。
5. 撰寫並執行程式，輸出圖表。
6. 驗證成果，說明觀察結果與分析限制。

## 3. 資料檢查與清理
- 畫圖前檢查並記錄：
  - 資料筆數、欄位名稱與資料型別。
  - 各欄位的缺失值數量。
  - 完全重複列及識別欄位重複情況。
  - 數值範圍、類別值及異常或不合理數值。
- 數值、日期與布林欄位須轉換成適當型別；轉換失敗的筆數與處理方式必須記錄。
- 缺失值不得直接視為 0；依分析目的選擇保留、排除或填補，說明理由及影響筆數。
- 不得自動刪除重複列；先判斷是否為合法的重複測量。
- 異常值須先檢查，不得只為使圖表好看而刪除。
- 不得修改或覆寫原始資料。
- 清理後資料另存至 data/processed/。
- 若必要欄位不存在，不得捏造資料；應說明限制，完成其他可執行的分析。

## 4. 視覺化工具選擇
- Matplotlib：適合靜態圖、精細版面控制、自訂標註及誤差棒。
- Seaborn：適合統計分布、群組比較、相關性及熱圖。
- Plotly：適合需要滑鼠提示、縮放、切換系列的互動探索。
- 使用者未指定工具時，依上述條件選擇並說明原因。
- 不得只依資料檔名決定套件。
- 優先使用現有套件；若需新增依賴，記錄用途與版本，不得擅自升級或移除現有依賴。

## 5. 圖表選擇與統計原則
- 比較類別數值：使用長條圖。
- 顯示時間或有序數值的變化：使用折線圖。
- 觀察數值分布：使用直方圖或箱型圖。
- 探索兩個數值變數的關係：使用散佈圖。
- 比較多個數值變數的相關性：使用相關係數熱圖，排除無分析意義的識別碼。
- 重複測量須依合理群組彙整；說明使用平均數或中位數，並在需要時呈現變異。
- 誤差棒須註明代表標準差、信賴區間或其他統計量。
- 不同目的或單位的指標不得直接混合比較。
- 比率須說明分子與分母；延遲等指標可同時觀察中位數與高百分位數，避免只看平均值。
- 相關性不得直接解釋為因果關係。

## 6. 圖表格式
- 每張圖須有明確標題。
- 座標軸須標示變數意義與適用單位。
- 多組資料須提供圖例，且相同類別跨圖使用一致顏色。
- 不得只靠顏色區分類別；必要時搭配線型或標記。
- 字型須支援使用的語言，避免缺字與亂碼。
- 依內容調整圖表尺寸，確保文字、圖例與標註不重疊。
- 標註重要峰值、差異或異常點時，不得遮擋主要資料。
- 長條圖數值軸原則上從 0 開始。
- 數值跨越多個數量級時可考慮對數尺度；使用前檢查零與負值，並清楚標示尺度。
- 資料過多時，可分組彙整、分面或抽樣；必須說明方式，隨機抽樣須固定種子。
- 不得透過刪除資料或調整尺度誇大差異。

## 7. 目錄與輸出
- data/raw/：原始資料，唯讀使用。
- data/processed/：清理或轉換後資料。
- src/：可執行的 Python 程式。
- outputs/figures/：靜態圖表。
- outputs/html/：Plotly 互動式 HTML。
- outputs/reports/：資料檢查與分析報告。
- README.md：環境需求、執行方式與成果說明。
- 原始資料位於其他路徑時，可直接讀取，不得擅自搬移。
- 程式使用相對專案路徑或可設定的輸入路徑，不得寫死個人電腦的絕對路徑。
- 檔名使用英文 snake_case，例如 algorithm_runtime_by_input_size.png。
- 靜態圖片預設輸出 PNG，解析度至少 150 dpi。
- Plotly 輸出可獨立開啟的 HTML，內嵌必要 JavaScript。
- 不得直接覆寫既有成果；檔名衝突時加入版本號。
- 不得將密碼、API key 或其他憑證寫入任何成果。

## 8. 執行與成果驗證
- 程式須能在無桌面視窗的雲端環境執行並輸出檔案。
- 不得只提供程式碼；完成前必須實際執行。
- 檢查使用欄位、單位、分組及彙整方式是否正確。
- 確認圖表與摘要數值一致。
- 確認輸出檔案存在、非空且可開啟。
- 檢視圖片是否有缺字、截斷、重疊或難以閱讀的問題。
- 檢查互動圖表的提示與系列切換是否符合設計；若無法實際操作驗證，必須註明未驗證。
- 執行失敗須說明原因並修正可處理的問題；不得宣稱未執行或失敗的檢查已通過。

## 9. 完成報告
完成後簡要列出：
- 資料品質問題與處理方式、影響筆數。
- 使用的工具、圖表及選擇原因。
- 程式執行指令與輸出檔案位置。
- 圖表支持的主要觀察，引用實際數值。
- 驗證結果、分析限制與尚未解決的問題。
